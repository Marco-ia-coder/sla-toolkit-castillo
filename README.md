# Toolkit para el Diseño, Cálculo y Verificación de SLA de Red

Este repositorio contiene un toolkit modular y reutilizable diseñado para construir, calcular y verificar Acuerdos de Nivel de Servicio (SLA) en servicios de red y telecomunicaciones[cite: 1, 2].

## ¿Qué es este Toolkit?
Es una herramienta real y reutilizable, pensada para usarse en asignaturas posteriores y en el mundo laboral con cualquier servicio de red[cite: 1]. Reúne cinco componentes clave: un método de diseño basado en ITIL 4 e ITU-T E.860, normas de medición internacionales, plantillas reutilizables, fórmulas de cumplimiento y una calculadora automatizada[cite: 1, 2, 3].

## Requisitos Técnicos
* **Python 3.x** instalado en el sistema.
* Librería **PyYAML** para procesar los archivos de objetivos del toolkit[cite: 3]. Puedes instalarla con el comando:
  ```bash
  pip install pyyaml

  ¿Cómo se usa?
  Para ejecutar la herramienta automatizada de verificación de cumplimiento y cálculo de créditos de servicio:
  python3 herramientas/calc_sla.py
