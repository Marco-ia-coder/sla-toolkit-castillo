# Glosario Técnico de SLA

Definiciones de los términos clave utilizados en la gestión, cálculo y verificación de servicios de red[cite: 3].

* **SLA (Service Level Agreement - Acuerdo de Nivel de Servicio):** Contrato formal entre un proveedor de servicios y un cliente que define el nivel de servicio esperado, las métricas de rendimiento y las consecuencias ante el incumplimiento[cite: 3].
* **SLI (Service Level Indicator - Indicador de Nivel de Servicio):** Métrica cuantitativa real que mide el nivel de rendimiento de un servicio (ej. latencia en milisegundos, porcentaje de paquetes perdidos)[cite: 3].
* **SLO (Service Level Objective - Objetivo de Nivel de Servicio):** Meta o umbral específico fijado para un SLI que el proveedor se compromete a cumplir (ej. disponibilidad $\ge 99.9\%$)[cite: 3].
* **SLR (Service Level Requirement - Requisito de Nivel de Servicio):** Necesidad de negocio del cliente expresada en su propio lenguaje antes de traducirse en objetivos técnicos[cite: 3].
* **OLA (Operational Level Agreement - Acuerdo de Nivel Operativo):** Acuerdo interno entre equipos o departamentos del proveedor para garantizar que se alcancen los SLA con el cliente[cite: 3].
* **MTBF (Mean Time Between Failures - Tiempo Medio Entre Fallas):** Mide la confiabilidad de un sistema, indicando el tiempo promedio estimado que opera de manera continua sin sufrir interrupciones[cite: 3].
* **MTTR (Mean Time To Repair - Tiempo Medio de Reparación):** Tiempo promedio que toma restaurar un servicio a su estado operativo normal tras una falla[cite: 3].
